# Sources: AM.II.E Landing Gear Systems

Category: Airframe (ACS Area II). Subject: E. Landing Gear Systems.

Use only these files. Fetch every link below. If a link doesn't load, check the
project files for the file name shown. If it isn't there, ask the student to
download it from the link and add it to the project.

## Notes for the tutor

- The section lists above say where to look first. They are not a promise that
  an element is fully covered. Check the text.
- Some skill elements are covered only in general terms, and the handbook defers to
  the manufacturer's data: S20 (master cylinder packing seals), S26 (landing gear
  down-lock switch) and S29 (tube landing gear). Say so when the student reaches them.
- Skis and floats (K13) are described as gear types only. No handbook chapter here
  gives ski or float maintenance procedures.
